# MyLib - A Simple Python Library

A dummy Python library demonstrating Sphinx documentation with Markdown support via MyST Parser.

## Features

- Simple utility functions
- Core functionality module
- Comprehensive documentation with Sphinx and MyST Parser
- Both RST and Markdown documentation sources

## Installation

```bash
pip install -e .
```

## Documentation

Build the documentation with:

```bash
cd docs
make html
```

Then open `_build/html/index.html` in your browser.
